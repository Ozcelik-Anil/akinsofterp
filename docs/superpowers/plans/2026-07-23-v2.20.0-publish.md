# akinsofterp v2.20.0 Entegrasyonu ve İki Dilli Yayın Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Yeni indirilen v2.20.0 paketini kurulu `akinsofterp` GitHub reposuna (`smurfspec/akinsofterp`) entegre etmek, repo genelinde tam güvenlik/KVKK taraması yapmak, GitHub ana sayfasında görünen tek `README.md`'yi iki dilli (EN+TR) hale getirmek, commit etmek ve son olarak eski v2.17.3 zip'ini silmek.

**Architecture:** Bu bir kod projesi değil, tek-dosyalık bir Claude skill içerik reposu. "Test" karşılığı `tools/consistency-check.ps1` (repo'nun kendi gizlilik/tutarlılık denetçisi, DB'ye bağlanmaz, salt-okunur, exit 0/1 verir) artı hedefli `grep` taramalarıdır. Kaynak paket (zip'ten extract edilmiş) dosya dosya hedef repoya senkronize edilir, frontmatter düzeltilir, taranır, README yeniden yazılır, commit edilir; push ve eski zip silme kullanıcı onayı/doğrulaması bekleyen ayrı adımlardır.

**Tech Stack:** Git, PowerShell 5.1 (`consistency-check.ps1`), Bash/grep/diff, Markdown.
